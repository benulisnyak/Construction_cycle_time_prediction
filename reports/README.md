# Reproduced results

These artifacts were generated on October 1, 2026 with Python 3.13.7, the included
datasets, and the versions in `requirements-lock.txt`:

```bash
python pipeline.py --manager-analysis
```

The text, CSV, and PNG artifacts from `outputs/` are retained here for review on
GitHub. The trained model remains in `outputs/model.cbm` and is regenerated by
the pipeline. See `run_config.json` for the model settings and row counts.

All artifacts were regenerated from the pseudonymized input datasets. Manager
labels and home IDs match those inputs; they are not original names or identifiers.
No source-to-public mapping is distributed. See
[data preparation and privacy](../docs/data_privacy.md) for the scope of these changes.

## Validation

| Metric | CatBoost | Training-fold median baseline |
| --- | ---: | ---: |
| Mean validation MAE | 30.9 days | 48.9 days |
| Mean validation RMSE | 40.4 days | 63.4 days |
| Mean validation R² | 0.582 | Not reported |

Mean training R² is 0.657. Each metric is an unweighted average over five
floor-plan-stratified folds. CatBoost improves MAE by 36.7% relative to the baseline.

The scatterplot shows underestimation of the longest builds, a limitation that
aggregate averages can obscure. Future evaluation should measure errors by
duration, community, and start date as well as overall performance.

## Predictions

`predictions.csv` contains 578 unique home IDs in input order, with no missing
values and positive integer duration estimates. Predictions range from 95 to
381 days, with a median of 167.5 days. Ground-truth outcomes for these homes are
not available, so their prediction accuracy is not measured here.

## Manager residuals

The manager-excluded model gives manager_06 the lowest mean actual-minus-expected
duration: approximately -17.5 days across 245 completed builds, with a descriptive
95% interval of approximately -23.6 to -11.4 days. This is an association adjusted
for the included property features, not an estimate of a causal manager effect.
See [methodology](../docs/methodology.md) for uncertainty and confounding limitations.
